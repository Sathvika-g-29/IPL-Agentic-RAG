Section 9: LangGraph Architecture Guide

Core Concept: In LangChain you built a linear chain: Query → Retriever → Prompt → LLM → Answer. In
LangGraph you build a stateful directed graph: nodes are processing steps (agents), edges are routing decisions,
and a shared State object carries information between nodes. The graph can loop, branch conditionally, and run
nodes in parallel — none of which a chain supports.
9.1 State Schema Design
Every node reads from and writes to a shared TypedDict state. Design your state before writing any node.
